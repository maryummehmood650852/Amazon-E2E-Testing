# Amazon E-Commerce End-to-End Testing

## Project Overview
This project focuses on end-to-end (E2E) test automation of e-commerce user workflows using Playwright and TypeScript.

The goal is to verify important customer interactions, including login, product search, product selection, and shopping cart operations, to ensure that the website behaves as expected throughout the shopping journey.

## Project Objectives
- Automate important e-commerce user workflows.
- Verify UI elements and page behavior.
- Validate expected results using assertions.
- Practice reliable browser automation with Playwright.
- Organize test cases using TypeScript.

## Tools & Technologies
- **Playwright:** End-to-end test automation
- **TypeScript:** Test scripting language
- **Git & GitHub:** Version control and repository management

## Test Scenarios

### 1. Login Workflow
- Interact with login page elements.
- Validate expected UI behavior during the login workflow.

### 2. Product Search
- Search for products using the website's search functionality.
- Verify expected page behavior and relevant UI elements.

### 3. Product Selection
- Interact with product listings.
- Validate product page elements and visibility.

### 4. Shopping Cart
- Perform shopping cart interactions.
- Verify expected UI behavior during cart operations.

## Automation Approach
- Used Playwright locators to identify page elements.
- Used browser actions to interact with the website.
- Applied assertions to validate expected behavior.
- Used Playwright's auto-waiting features to improve test reliability.
- Organized automated tests using TypeScript and Playwright's test structure.

## Key Learning Outcomes
- Understanding end-to-end testing workflows.
- Writing browser automation scripts.
- Working with locators, actions, and assertions.
- Validating UI behavior across multiple user interactions.
- Structuring automated tests for maintainability.
